# 问题二程序与论文说明

| 指标 | 三类分开运输 | 最终联合方案 | 改进 |
|---|---:|---:|---:|

最终方案覆盖全部4000人，独立Validator结果为 `valid=true`、`issue_count=0`。

## 二、算法相对原稿的变化

原稿计划采用“Q1骨架顺序插入 + Regret插入 + ALNS”。实际程序改为更容易严格复现的：

1. 三类需求分开运输MILP基线；
2. 燃油可行候选闭合路线生成；
3. 带逐航段容量的整数主问题；
4. 区间着色把聚合分配无损还原到具体架次；
5. 自适应三设施候选列扩展，并保留完整词典序历史最优。

候选路线的人员分配变量是OD层人数，容量约束在每个航段分别计算。因此一条路线累计运输人数可以超过座位数，但任一时刻在机人数不会超过容量。

## 三、程序文件

| 文件 | 功能 |
|---|---|
| `code/src/solver/q2.py` | 候选序列、燃油可行变体、取送兼容、逐航段MILP、区间着色和三设施列扩展 |
| `code/src/solver/data.py` | 同时读取Q1、Q2聚合需求 |
| `code/src/solver/importer.py` | 读取并复算Q1、Q2已有方案 |
| `code/scripts/05_solve_q2.py` | Q2统一运行入口、结果导出、Validator和最优结果保留 |
| `code/scripts/plot_q2_results.py` | 生成中文方法对比图和代表性混合架次状态图 |
| `code/tests/test_q2_solver.py` | Q2数据规模、取送顺序和座位复用测试 |

## 四、输出文件

## 五、运行方法

进入 `code` 目录并安装依赖：

```bash
pip install -r requirements.txt
```

复算扩展双设施候选池：

```bash
python scripts/05_solve_q2.py \
  --nearest-neighbors 3 \
  --high-demand-nodes 10 \
  --time-limit 180 \
  --variant-cache outputs/q2/pair_n3_h10.pkl \
  --skip-separate \
  --promote
```

复算三类分开运输基线：

```bash
python scripts/05_solve_q2.py \
  --nearest-neighbors 3 \
  --high-demand-nodes 10 \
  --time-limit 120 \
  --variant-cache outputs/q2/pair_n3_h10.pkl \
  --separate-only
```

独立检查最终CSV：

```bash
python scripts/validate_solution.py \
  --question q2 \
  --routes outputs/q2/best/q2-routes.csv \
  --assignments outputs/q2/best/q2-assignments.csv \
  --data-dir data/raw \
  --json
```
