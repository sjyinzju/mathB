## 2. 新增优化机制

问题三现采用以下交替框架：

1. 从问题二缓存读取 3116 条燃油可行路线变体；
2. 根据时间窗构造共同起飞区间，进行混合 OD、逐航段容量拼载；
3. 使用 24 架具体飞机的区间日历处理属地、机型、运营时段和 30 min 周转；
4. 建立稀疏 0—1 整数模型，全局重分配全部人员；
5. 固定人员集合，用更短的同机场、同机型路线替换冗余路线；
6. 搜索其他机型、所属机场、具体飞机和起飞时刻；
7. 删除可能冗余的停靠点，再由整数模型修复全局人员分配；
8. 仅接受人员服务水平不下降、飞机时间严格下降且通过硬约束检查的方案；
9. 第二阶段使用瓶颈 OD 引导路线构造，并强制保留全部 160 名临时人员。

“删停靠—全局重分配”邻域是本版提升最大的部分。它允许先破坏某个航班原有人员组合，再从全部航班中重新寻找人员位置，因此能发现固定人员分组下不可见的路线缩短机会。

## 3. 求解界限

### 第一阶段

- 客公里工作量保守下界：12389 min；
- 机场—机型分层连续多商品流全局下界：14125 min；
- 有限候选路线池连续主问题参考界：15198 min（不是原问题全局下界）；
- 当前最佳可行基准：30546 min；
- 按增强全局下界计算的认证区间宽度：53.758%；
- 结论：30546 min 是当前最佳可行值，尚未证明第一阶段全局最优。

增强模型把机场属地、机型座位数、真实航段时间、海上最小停靠时间、飞机流守恒和
各机场—机型机队的7天总可用时间纳入连续松弛。任何原排班都能映射到该模型，而模型
允许连续架次、旅客拆分与换乘，并放松日期、时间窗、逐机冲突、周转和加油，因此其
14125 min不会高估原问题最优值。相较12389 min，下界提高1736 min，认证区间缩小
5.683个百分点。

15198 min由3116条缓存路线构成的连续主问题得到。由于有限候选池可能漏掉更优路线，
它只能用来评价现有路线池，不能和全局下界混用。

### 第二阶段

- 临时人员总数及理论上界：160；
- 最终完成：160；
- 绝对间隙：0；
- 相对间隙：0%；
- 最终飞机时间：30510 min，比第一阶段上界少 36 min。

因为目标值已经达到临时人员总数160，第二阶段“最大化临时任务服务人数”的首要目标得到全局最优证明。但30510 min尚未被证明是完成4000人时的最短飞机时间。

## 5. 运行命令

在 `code` 目录执行：

```bash
python -m pip install -r requirements.txt

python scripts/06_solve_q3.py \
  --run-id q3-deep-reproduce \
  --seeds 3 \
  --deep \
  --polish-rounds 3 \
  --stage1-destroy-trials 140 \
  --stage2-destroy-trials 340 \
  --assignment-milp-time 90 \
  --promote

python scripts/validate_solution.py \
  --question q3 \
  --routes outputs/q3/best/q3-routes.csv \
  --assignments outputs/q3/best/q3-assignments.csv

python scripts/plot_q3_results.py \
  --routes outputs/q3/best/q3-routes.csv \
  --assignments outputs/q3/best/q3-assignments.csv \
  --output-dir ../figures

python scripts/08_compute_q3_enhanced_bounds.py \
  --variant-cache outputs/q2/pair_n3_h10.pkl \
  --time-limit 300
```

深度破坏—修复会反复求解稀疏整数模型，完整复现时间明显长于基础模式。竞赛提交时应直接保留 `outputs/q3/best/` 中已经通过校验的结果，并把完整运行日志作为支撑材料。

## 6. 仍值得继续做的优化

| 优先级 | 方向 | 作用 |
|---:|---|---|
| 1 | 在分层多商品流上加入有效不等式或列生成 | 继续收紧当前53.758%的全局认证区间 |
| 2 | 将破坏—修复候选按对偶价格或瓶颈航段评分 | 减少无效整数修复，提高复现速度 |
| 3 | 对1—2个日期建立局部CP-SAT/MILP联合模型 | 同时优化路线、起飞时刻和具体飞机，继续降低30510 min |
| 4 | 增加多种子统计和运行时间分布 | 提高实验可信度和论文完整性 |
| 5 | 加入天气、故障和飞行时间扰动 | 提高实际排班鲁棒性，但不是当前确定性题目的首要任务 |
